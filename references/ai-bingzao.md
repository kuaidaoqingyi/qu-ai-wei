# AI 病灶识别表

先判断病灶族，再决定动作。词语命中只算线索；真正要看的是信息、责任、对象和推进有没有被遮住。需要核对大量固定套话时，再读 `ai-cliche-library.md`。

表内动作是候选操作，始终服从主文件的编辑范围。默认轻改时，整句、整段删除和重排只列建议。每次新增病灶，同时给出修改条件和一个应保留的反例。

## 最高优先级

| 病灶 | 典型信号 | 核心问题 | 建议动作 |
| --- | --- | --- | --- |
| 没有对象 | 开头只讲时代、行业、趋势 | 没有人、没有事、没有读者问题 | 换成具体人、事件、场景或麻烦 |
| 没有真主语 | “得到了提升”“实现了优化” | 谁做、谁判断、谁负责不清 | 只用原文已知主语；未知施事者不得补造 |
| 无源权威 | 研究、数据、专家没有出处 | 借模糊权威撑结论 | 保留归因及不确定性，正文外提示缺来源；不升级成事实 |
| 假具体 | “某个用户”“一个典型案例”没有细节 | 例子只有外壳 | 用原文细节补全；没有就删例子壳 |
| 常识补写 | 抽象的效率、体验、趋势被改成备课、反馈、岗位职责等具体场景 | 具体细节看似合理，原文没有依据 | 删除新增细节；允许改后稿保持简短 |
| 借来的作者感受 | 原文没有第一人称，改稿突然出现“我试了”“我很震惊” | 为了人味编经历和情绪 | 删除虚构内容；只保留原文可追溯的作者材料 |
| 作者退出现场 | 原文有真实测试、采访、使用或判断过程，改稿只留下结论 | 作者声音被资料腔压平 | 恢复已有过程和判断来源 |
| 推断升级 | 招聘变化被直接写成战略转向，相关关系被写成因果或瓶颈 | 改稿替作者下了更强结论 | 恢复原证据等级和限定词；缺依据的机制删掉 |
| 信息复读 | 相邻段落换词重复同一结论 | 字数增加，认识没有前进 | 合并或删除后一段 |
| 占位符或对话残留 | “此处插入案例”“当然可以，以下是” | 暴露提示词和界面残留 | 一票否决，删除后全文重读 |
| 假引用 | 文献、DOI、链接或归属对不上 | 证据可能有误 | 单列待核实项；未获准核查或删论据时不擅改、不补来源 |

## 结构与推进

| 病灶 | 典型信号 | 核心问题 | 建议动作 |
| --- | --- | --- | --- |
| 宏大时代开场 | 技术浪潮、时代背景、重要趋势先铺一段 | 读者迟迟看不到事情 | 删除，直接进入事件或问题 |
| 二元对比假戏剧 | 先否定 A，再把 B 写成顿悟 | 普通转折被包装成洞察 | 换句式；真实排除、纠错及责任信息必须保留 |
| 否定式列举 | 连续排除多个答案后才说重点 | 绕路制造悬念 | 无独立含义才精简；保留实际排除的选项 |
| 价值拔高骨架 | 普通事实被抬成宏大意义 | 姿态大于信息 | 降到动作、结果或责任 |
| 三件套排比 | 三个抽象词并列，每项都不展开 | 用完整感代替分析 | 只合并同义空项，不按数量删独立信息 |
| 对称填充 | 成对结构反复出现，取舍不明 | 为整齐牺牲判断 | 写清优先级和代价 |
| 破折号穷举 | 破折号后跟一串抽象名词 | 用标点制造揭晓感 | 拆成正常句，删无信息项 |
| 机械递进 | 首先、其次、最后只负责排版 | 顺序没有真实逻辑 | 改成时间、因果、取舍或动作顺序 |
| 戏剧化碎句 | 多个极短句只为制造力量感 | 节奏表演压过事实 | 合成正常句 |
| 反问式铺垫 | 问题没有真实悬念，答案立刻自报 | 延迟进入事实 | 直接给判断和依据 |
| 信息增量不足 | 一段只解释上一段已经说过的话 | 文章原地踏步 | 标记合并建议；不为信息密度增写事实 |
| 感慨膨胀 | 后半段连续写“意义、启示、值得思考” | 情绪重复，信息密度骤降 | 只留最有用的一次收束 |
| 结尾拖堂 | 结论已成立，后面又总结两三段 | 文章停不下来 | 在最后一个有效事实、动作或画面处停住 |
| 挑战展望公式 | 先承认困难，再统一展望光明未来 | 任何题目都能套 | 写具体困难、应对或真实未知 |
| 和稀泥收尾 | 各有利弊、因人而异、取决于需求 | 回避取舍 | 写明条件和选择 |
| 无对象的辩护 | “不要误会，我并不想……”没有回应内容 | 凭空制造对立 | 精简空辩护；保留真实异议和适用边界 |
| 首句复读标题 | 标题后又预告本节会讲标题 | 延迟进入信息 | 仅重复时提删改建议；定义、限制和数据保留 |

| 病灶 | 典型信号 | 核心问题 | 建议动作 |

| 高频词扎堆 | 赋能、助力、闭环、抓手、生态、维度、本质上密集出现 | 熟词制造专业感 | 保留最准确的一项，其余换成动作 |
| 肤浅分析尾巴 | 体现、彰显、标志、奠定、反映更广泛问题 | 事实后面硬挂意义 | 删除尾巴 |
| 虚假主语 | 技术、方案、平台被写成人类行动者 | 责任关系消失 | 写清谁用它做了什么 |
| 翻译腔 | 长定语、被动堆叠、动作压到句尾 | 中文推进迟缓 | 缩短主语，把动作提前 |
| 同义词循环 | 同一对象反复换称呼 | 追求词汇丰富导致指代混乱 | 固定称呼 |
| 虚假范围 | “从 X 到 Y”两端不在同一尺度 | 人为制造跨度 | 改成真实范围 |
| 过度限定 | 多个可能性词叠加 | 重复表达同一层不确定性 | 只压同义重复，不合并证据、范围和状态等不同限定 |
| 抽象名词堆叠 | 范式、格局、系统能力等大词连用 | 没有可感知对象 | 换成场景、动作或结果 |
| 通稿夸赞腔 | 标杆、里程碑、不可或缺、备受瞩目 | 只有评价，没有证据 | 换成事实；撑不住就删 |
| 双词并联填充 | 两个词在当前语境中表达同一件事 | 同义复述，未增加独立含义 | 仅确认同义重复时合并；效率与体验、准确性和一致性可各自成立，未展开也须保留 |
| 系动词回避 | 用充当、代表、拥有绕开“是、有” | 句子故作复杂 | 能用“是、有”就直接用 |
| 冗长动作 | “进行检查”“开展调整”反复出现 | 动作被空动词包住 | 可直接写动词；保留计划、正在、尚未及次数 |

## 信息增量判定

内部给每段标一个主要功能：事实、机制、经历、判断、动作、转场。

- 相邻两段功能相同、结论相同，只能提示检查重复；先核对各自的事实、例子、条件、作者态度和转场，确无独立信息才列合并建议。
- 新段落只增加“更重要、更深刻、更值得思考”等程度词，视为零增量。
- 一个例子可能承担说明、证据、作者经历或理解辅助；未改变结论不构成删除理由，轻改时保留。
- 结论出现后，后文只换说法解释意义，视为结尾拖堂。
- 删除一段后事实链和论证链都不受影响，可列为删改建议；获准压缩后再执行。

## 快速判定

- 删除第一段后正文照常成立，多半是空开场。
- 否定部分不承担排除、纠错或责任信息时，才可能是空铺垫。
- 并列项顺序可互换，不代表含义相同；逐项检查是否表达独立功能、要求、主张或适用对象，独立项全部保留。
- 破折号后是一串抽象词，多半是穷举汇总。
- 句子里找不到施事者，先查原文是否本就未知，不猜一个主语。
- 后半段连续三段没有新事实、机制和动作，多半在重复感慨。
- 第一人称内容无法追溯到原文，多半是借来的作者感受。
- 原文只显示相关变化，改稿却写成因果、战略或能力瓶颈，多半是推断升级。
- 新增的具体动作和对象只能靠常识解释，无法在原文定位，多半是常识补写。

## 防止误杀

- 技术文档中的系统主语、字段名、被动句可以保留。
- 正式汇报需要结构，不要强行改成聊天。
- 广播站口语路标可以保留，前提是帮助听众跟上。
- 承载事实的抽象句先保事实，再改外壳。
- 原文没有动作和场景时，不用常识替它补具体案例。
- 引用、标题、法律和政策原文即使命中套话，也保持原样。

## 高风险保留例

以下为自拟教学例，只说明边界，不作为生成正文的素材库。

| 命中线索 | 应保留的例子 | 不可跨越的边界 |
| --- | --- | --- |
| 否定对比 | “不是员工没提交，而是审批人还没确认。” | 可改成“员工已提交，审批人还没确认”，不能省掉员工已提交的信息 |
| 三项列举 | “支持查询、导出和撤回。” | 三个独立功能全部保留 |
| 双项未展开 | “这次评估同时关注准确性和一致性，数据尚未收齐。” | 两个指标和未完成状态都保留，不挑一项替作者取舍 |
| 同义重复 | “先确认收到了款项，也就是确认款项已经到账。” | 确认两处指同一条件后可合并，不新增支付方式或核验步骤 |
| 无主被动 | “记录被删除了，操作者尚不清楚。” | 不能改成系统或某个员工删除了记录 |
| 无源归因 | “服务商称能省时，我们尚未验证。” | 不能写成作者已确认省时，也不补报告或专家姓名 |
| 连接词 | “甲组核库存，同时乙组核付款；两组完成后再发货。” | 并行工作和发货前置条件均保留 |
| 多个限定 | “仅在内测中可能有效，目前还未复测。” | 范围、可能性和验证状态是三层信息 |
| “进行” | “计划周三进行检查，今天尚未开始。” | 可删空动词，不能改成检查已完成 |
| 四字表达 | “离线可用、权限可控、记录可查。” | 每项都有独立要求，不因节奏整齐删项 |
| 首句像标题 | 标题“使用限制”下写“仅限内部试用”。 | 具体限制必须保留 |
| 作者犹豫 | “我还有点不放心，准备再试两天。” | 不替作者变成坚定推荐或明确否定 |
| 真实边界 | “这一方案不覆盖跨部门审批。” | 不把能力限制当作多余辩护 |
