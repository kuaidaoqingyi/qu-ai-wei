# 快刀青衣文风参考

当用户说“按我的文风”“快刀青衣文风”“广播站文风”“像我早期文章”“说人话但要像我”时使用。先完成 `ai-bingzao.md` 的去味诊断，再结合 `broadcast-style.md` 做补味，最后用本文件校准作者声音。

本文件来自虎嗅专栏样本的初步提炼：2015 年早期文章、2019 年组织管理文章、2026 年 AI 评论文章。它是风格规则，不是事实来源；不要把样本文中的事件、数据或经历搬进用户新稿。

## 一句话标准

快刀青衣的“说人话”，不是把句子改口语，而是把抽象问题拉回一个具体人、一个具体场景、一段真实代价，然后给出一个愿意负责的判断。

## 稳定骨架

1. **先现场，后背景。** 不从“近年来/随着/在 AI 时代”开头，先给一个具体事件、反常点、人物处境或作者反应。
2. **作者在场。** 文本里要有一个正在判断的人：我看到了什么、哪里不对劲、我为什么多想一步。
3. **抽象词必须落地。** 透明、自驱、协作、验收、负责、风险这些词，后面要接动作、代价或责任主体。
4. **拆假叙事。** 不只问“这事对不对”，还问“谁这么说、在什么条件下成立、谁受益、谁承担后果”。
5. **强判断从故事里长出来。** 不靠拔高语气制造力量，靠具体经历、事实链和反常细节支撑判断。
6. **结尾给读者一个可复用问题。** 让读者下次遇到类似事，知道先问哪一个问题。

## 早期强风格

早期文风最强的地方：

- 现场感重，敢写狼狈、失败、尴尬和不体面。
- 比喻密，用生活、江湖、段子把商业和管理话题去庄严化。
- 句子有个人风险，不追求四平八稳。
- 分条也不模板，因为每条都有真实故事、具体动作或具体人。

迁移时保留：

- 具体场景开头。
- 自嘲和失败经验。
- 对虚假正确话术的拆穿。
- 从荒诞细节里抠出管理判断。

迁移时谨慎：

- 不复制粗口、性别化表达和过时冒犯性比喻。
- 不为了像早期文章而故意油滑、夸张或抖包袱。
- 不把强语气误当强判断。

## 近期理性风格

2024 年后的文章更重：

- 来源、数据、时间线和利益关系。
- 对可信度分层，而不是一刀切。
- 从产品、组织、监管和商业动机多层推进。
- 先承认真信号，再拆夸张叙事。

AI 话题尤其要落到：

- 谁公布的数据。
- 这个数据在什么条件下成立。
- 有没有第三方验证。
- 谁有能力验收结果。
- 谁会从这个叙事里获益。
- 谁最后签字负责。

## 改写动作

| 原文问题 | 改写动作 |
| --- | --- |
| 开头抽象 | 换成具体事件、反常点、人物处境或作者第一反应。 |
| 只有结论 | 补一个支撑结论的真实动作、代价、时间线或责任主体。 |
| 只有信息整理 | 加入作者判断：哪里值得信、哪里要降一档信任。 |
| 管理概念太空 | 改成“谁做了什么，谁多承担了什么，机制怎么变”。 |
| AI 话题太玄 | 落到验收、复现、审核、签字、谁受益。 |
| 结尾鸡汤 | 改成“以后再看到类似事，先问什么”。 |

## 常用判断方向

这些是方向，不是固定句式：

- 这件事真正麻烦的地方，不是它看起来多新，而是它把判断责任推给了谁。
- 一个数据如果是自己出题自己答，就先降一档信任。
- 真正稀缺的不是产出速度，而是验收速度。
- 管理上的好词，最后都要落到谁知道信息、谁能发起动作、谁愿意负责。
- 技术能加速交付，但人的习惯、组织信任和责任分配是慢变量。

## 禁止项

- 不编作者亲身经历。
- 不模仿粗口和冒犯性段子。
- 不把专业内容改成鸡汤或段子。
- 不为了“人味”故意加错别字、口头禅和网感词。
- 不用“不是而是”堆出假深刻；只有真实误解需要拆时才用。
- 不把样本文中的虎嗅、罗辑思维、得到、Anthropic 等事实搬到无关文本里。

## 最后回读

改完后问四个问题：

1. 开头有没有一个具体的人、事、场景或作者反应？
2. 抽象判断有没有落到动作、代价、机制或责任主体？
3. 文本有没有回答“谁受益、谁负责、谁验收”里的至少一个？
4. 结尾是不是留下一个下次可复用的问题，而不是情绪升华？
